# Amadeus · 新约能天使

《明日方舟》新约能天使的 Amadeus 风格 AI 助理终端：3D 半身像、中日双语官方语音、实时语音通话（WebRTC + Whisper + TTS），后端接任意 OpenAI 兼容接口。

```bash
npm install && npm run setup   # 取回立绘与 38 条台词的中配/日配，约 13 MB
npm run dev                    # http://127.0.0.1:1002
```

立绘、语音、模型与动作素材都不入库，只留获取地址与 SHA-256。非官方同人作品，仅供学习；素材版权归鹰角网络与原作者。

实现细节与踩坑记录见 [NOTES.md](NOTES.md)。
